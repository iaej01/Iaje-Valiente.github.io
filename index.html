Developer guide: hand-tracking virtual mouse

Overview

A Python program that moves the mouse cursor from hand gestures seen by a camera. It uses OpenCV for video, MediaPipe for hand tracking, and a One Euro Filter to smooth the cursor.

1. Install the requirements

Install Python 3, then the libraries:

pip install opencv-python mediapipe SpeechRecognition pygame pyaudio

2. Connect an Android phone as the camera

  1. Turn on USB debugging on the phone and connect it by USB.
  2. Start the server in the IP Webcam app.
  3. Forward the port from your computer:
adb devices
adb forward tcp:8080 tcp:8080

The video stream is then at http://localhost:8080/video.

3. Run the program

python <script-name>.py

Features

  • Cursor control from hand tracking, smoothed with a One Euro Filter.
  • Face-gated controls.
  • Voice commands through SpeechRecognition, starting with “Jarvis”.
  • Command sounds played with pygame from the command_sounds folder.
  • An Iron Man face overlay (ironman.png).

Troubleshooting

  • No video: run adb devices and make sure the phone is listed, then repeat the port forward.
  • Cursor shakes or lags: adjust the filter’s cutoff and beta settings.
  • Voice commands not heard: check the microphone and that PyAudio is installed.
